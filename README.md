# Lucky Arcade v2 — Telegram Mini App demo

## Добавлено
- Профиль игрока (имя Telegram, если приложение открыто в Telegram).
- Сохранение баланса, рекорда, количества раундов и даты бонуса в localStorage.
- Ежедневный бонус +50 виртуальных очков.
- Локальный рейтинг лучших результатов.
- Слоты и колесо удачи.

## Запуск
1. Разместите `index.html` на HTTPS-хостинге (например, GitHub Pages, Cloudflare Pages или Netlify).
2. Создайте бота через @BotFather.
3. Укажите URL страницы в настройках Mini App / Web App бота.
4. Откройте приложение через Telegram.

## Ограничения демо
- Прогресс хранится в браузере на конкретном устройстве. При очистке данных браузера он может потеряться.
- Лидерборд не общий для всех пользователей. Для синхронизации профилей между устройствами и общего рейтинга нужен сервер и база данных.
- Только бесплатные виртуальные очки: нет денежных ставок, депозитов, покупок или вывода денег.
